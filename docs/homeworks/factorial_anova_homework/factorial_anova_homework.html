Note📚 Where these data come from

Source: Quinn, G.P. & Keough, M.J. (2002), Experimental Design and Data Analysis for Biologists, Ch. 9 — Box 9-2. The original study is Reich, P.B., Walters, M.B., Ellsworth, D.S., et al. (1998), Oecologia 114: 471–482.

Leaf area was measured on woody plants at four locations spanning a huge climatic range — New Mexico, South Carolina, Venezuela and Wisconsin — and each plant was classified by growth form: shrub or tree. The question is whether the shrub/tree difference in leaf area is the same everywhere, or whether it depends on where you are.

In class you analysed the crayfish common-garden experiment. This is the same design class — a two-factor factorial with badly unequal cell sizes — on a different question, and it behaves differently in a way worth finding.

Warning⚠️ Three things about this file
  1. It uses a . to mark a missing value. Check class() on your response column before you model anything — if it came in as character, that is why. read_csv(..., na = c("", "NA", ".")) is the fix.
  2. The cell sizes run from 2 to 21. Every cell is filled, so every term is estimable, but nothing about this design is balanced.
  3. Look at a histogram of the raw response before you fit. Leaf areas are a classic case where the untransformed scale will not pass a normality check. You are allowed to transform — but say so, and say why.

Assignment Overview

This homework assignment analyzes the Reich et al. leaf-area data to examine whether the difference in leaf area between shrubs and trees is consistent across four locations, using a two-way factorial ANOVA on an unbalanced design.

Learning Objectives

By completing this assignment, you will be able to:

  1. Understand two-way ANOVA concepts and applications
  2. Perform exploratory data analysis for factorial designs
  3. Conduct two-way ANOVA analysis
  4. Test statistical assumptions for ANOVA
  5. Interpret main effects and interactions
  6. Create publication-quality figures
  7. Write scientific methods and results sections

Data Description

The dataset contains leaf-area measurements on woody plants sampled at four locations, each plant classified as a shrub or a tree. There are 58 rows, one of which has a missing response.

Key variables:

  • - LOCATION: sampling location (Newmex, Scarolin, Venezuel, Wiscons) — 4 levels
  • - FUNCTION: growth form (Shrub vs Tree) — 2 levels
  • - LEAFAREA: leaf area (cm²) — the response variable

Note that FUNCTION is a reserved word in R. janitor::clean_names() will lower-case it, and you should rename it to something safe — func, say — before you use it in a formula.

2.1 Analysis Type and Model

Type of Analysis: Two-way factorial ANOVA

Model Equation: Leaf area = μ + Location + Function + (Location × Function) + ε

Where:

  • - Leaf area = leaf area, cm² (transform it if your diagnostics tell you to)
  • - Location = sampling location (4 levels)
  • - Function = growth form (Shrub vs Tree)
  • - Location × Function = interaction between the two
  • - ε = random error

Hypotheses:

  • Main Effect
    • - Location:
      • - H₀: μ_Newmex = μ_Scarolin = μ_Venezuel = μ_Wiscons
      • - H₁: At least one location mean differs from the others
    • - Function:
      • - H₀: μ_Shrub = μ_Tree (no difference in leaf area between growth forms)
      • - H₁: μ_Shrub ≠ μ_Tree
  • Interaction Effect:

    • - H₀: The shrub–tree difference is the same at every location

    • - H₁: The shrub–tree difference depends on location

Variables:

  • - Response: leafarea (continuous, cm²)
  • - Factor 1: location (categorical, 4 levels)
  • - Factor 2: func (categorical, 2 levels: Shrub, Tree)

Because the design is unbalanced, use Type III sums of squares — car::Anova(model, type = 3) — and set options(contrasts = c("contr.sum", "contr.poly")) before you fit the model.

4.2 Effect Sizes

The effectsize package does this in one line each — no sums of squares by hand, and it reports a confidence interval with every estimate. It is already loaded in the setup chunk at the top.

▶ Run this on your fitted model:

# eta_squared(leaf_model, partial = FALSE)
#
# omega_squared(leaf_model, partial = FALSE)

Each gives you one row per term — location, func and location:func — with the estimate and its 95% CI.

To get the small / medium / large label without looking it up in a table:

# eta_squared(leaf_model, partial = FALSE) %>%
#   interpret_eta_squared()

What the two numbers mean

  • Eta-squared (η²) is the proportion of total variance explained by that term: η² = SS_term / SS_total. If η² = 0.10 for func, then 10% of the variance in leaf area is explained by whether the plant is a shrub or a tree.
  • Omega-squared (ω²) is the same idea corrected for bias. η² always overestimates a little, especially with small samples; ω² is the more honest estimate. They will be close.

Use partial = FALSE so the terms are fractions of the same total and can be compared to each other. (partial = TRUE, the default, divides each term by itself plus the residual, which is useful but does not add up to anything.)

Interpretation guidelines

Effect Size     η² / ω²       Interpretation
Small           0.01          1% of variance explained
Medium          0.06          6% of variance explained
Large           0.14          14% of variance explained
