Homework 5 — Study Design & Sampling

Finding the real replicate

Two coasts, 1022 snails, 18 sites: the same comparison analysed at two different levels of replication, and what happens when you pick the wrong one.
Author

Bill Perry

Worksheet: Finding the Real Replicate

📥 Littoraria data 📥 Tools script (.R) 📥 Script skeleton (.R)

The study. Littoraria angulifera is a mangrove periwinkle found on both sides of the tropical Atlantic. Gotelli & Ellison’s dataset holds shell measurements from 1022 snails collected at 18 sites — nine on the East Atlantic coast of Africa, nine on the West Atlantic coast of the Americas.

The question. Are West Atlantic snails bigger than East Atlantic snails?

In class you took a small, tidy, balanced experiment and asked whether one of its treatment arms earned its place. This is the same workflow on a dataset that is none of those things — 1022 rows, wildly uneven sampling, and nobody assigned anything to anything. One decision in Part 2 determines whether you get the right answer, and the data will not warn you if you get it wrong.

Columns: site, coast, latitude, longitude, shell_breadth_mm, shell_height_mm, aperture_length_mm.

Tip

🚀 If you finish early: site_df has an n_snails column. A site mean built from 301 snails is a far more precise estimate than one built from 3, yet the site-level t-test treats them as equally reliable. Look up weights = in ?lm and run a weighted version. Does weighting by n_snails move the p-value toward the snail-level answer or the site-level one, and does that seem right to you?

Part 7 · The figure you hand in

The only plot with labels, a theme and a title. Show both levels at once so the reader can see where the uncertainty actually lives.

▶ Run this:

# ── Part 7.1 · The figure you hand in ───────────────────────────────────
final_plot <- ggplot(site_df, aes(coast, mean_breadth)) +
  geom_jitter(aes(size = n_snails), width = 0.12, alpha = 0.6) +
  stat_summary(fun = mean, geom = "crossbar", width = 0.4, linewidth = 0.4) +
  labs(
    title = "Shell breadth of Littoraria angulifera by coast",
    subtitle = "One point per site (n = 9 per coast); point size is snails sampled",
    x = "Coast",
    y = "Mean shell breadth (mm)",
    size = "Snails"
  ) +
  theme_regular(base_size = 12)

final_plot

ggsave(
  "figures/littoraria_figure.pdf",
  plot   = final_plot,
  width  = 6,
  height = 4,
  units  = "in"
)
