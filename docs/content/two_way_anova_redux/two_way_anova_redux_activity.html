Activity: Two-Way ANOVA Redux

The same machinery on data that fights back

Hands-on activity: a second factorial ANOVA on the genuinely unbalanced Sargent & Lodge crayfish growth data — writing the factorial model, reading Anova(type = 3), using emmeans four ways to unpack an interaction, and checking whether a failed assumption changed the answer.
Author

Bill Perry

In-class Activity 14: Two-Way ANOVA Redux

Today’s Objectives

  1. Write a two-factor model with an interaction, and say what each term is
  2. Read Anova(model, type = 3) on an unbalanced design
  3. Use emmeans four ways: marginal, simple effects both directions, interaction contrast
  4. Check the model with check_model() and decide whether a violation mattered

🧩 Block 2 — The model and its table (lecture Parts 3–5)

Section 3 · Write the factorial model

A two-factor model with an interaction has three terms. Written out in full:

# the shape, written the long way:
#   model <- lm(y ~ x1 + x2 + x1:x2, data = df)
#
# and the shorthand that means exactly the same thing:
#   model <- lm(y ~ x1 * x2, data = df)
  • x1 — the first main effect
  • x2 — the second main effect
  • x1:x2 — the interaction, which asks whether x1’s effect is the same at every level of x2
  • x1 * x2 — shorthand for all three

Type III sums of squares need sum-to-zero contrasts, and contrasts are fixed when lm() runs. So the order is always set → fit → test.

# the shape:
#   options(contrasts = c("contr.sum", "contr.poly"))
#   model <- lm(y ~ x1 * x2, data = df)

▶ YOUR CODE: set the contrasts, then fit cray_model with growth_per_day as the response and range and lake as the two factors.

✏️ Q6: Write out in words what each of the three terms is asking.
