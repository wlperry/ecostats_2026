Activity: GLM & Logistic Regression

Generalized linear models

Hands-on activity: what to do when a linear model’s assumptions fail on count data. Gaussian, Poisson, and negative binomial GLMs on Gotelli & Ellison’s Galapagos island-biogeography data, a count where the Poisson actually fits, then logistic regression on Whitlock & Schluter’s guppy cold-tolerance data.
Author

Bill Perry

In-class Activity 15: Generalized Linear Models

Today’s Objectives

  1. Fit a linear model to count data and watch it predict something impossible
  2. Say why the week-6 log transformation is a fix, but not the same model
  3. Check that a Gaussian GLM reproduces lm() exactly
  4. Fit a Poisson GLM, measure overdispersion, and say what it does to your p-values
  5. Fit a negative binomial GLM and confirm it fixed the problem
  6. Find a count where the Poisson is the right model, on your own

Where this fits

For the last three weeks every model has been a linear model — one-way ANOVA, factorial, and the redux. All of them assume the residuals are normal with constant variance. That is a fine assumption for body mass or growth rate.

It is a bad assumption for a count. A count is a whole number, it cannot go below zero, and its variance usually grows with its mean. Today is what you do instead.

A generalized linear model keeps the linear part and swaps out two things:

Component What it is Example
Random the response’s distribution Poisson for counts
Systematic the predictors log(area_km2)
Link connects the mean to the predictors log for counts, logit for binary
Response looks like Family
continuous, symmetric gaussian — this is just lm()
counts poisson
counts, variance > mean negative binomial (glm.nb)
binary — present/absent binomial(link = "logit")
positive, continuous, skewed Gamma

✏️ Q3: Which assumption failed, and which one came back fine? Be careful here — do not report a violation the test did not find.

✏️ Q4: Look at that prediction interval. What is its lower bound, and what would that mean in the field?

✏️ Q5: The p-value for area_km2 is about 0.016. Did this model earn the right to that number?

💡 Key idea: this is the moment the linear-model toolkit runs out — and notice how it ran out. The variance was fine. What broke is that the normal distribution has no lower bound, so the model is free to predict −111 plant species. No amount of extra data fixes that; it is the distribution that is wrong.

Section 3 · You already know one fix

In week 6 you handled this with logs. Do it again and see how well it works.

▶ Type this yourself:

# ---- 3 You already know one fix --------------------------
lm_log <- lm(log10(n_species) ~ log10(area_km2), data = g_df)
summary(lm_log)

shapiro.test(residuals(lm_log))

check_heteroscedasticity(lm_log)

R² rises from 0.33 to 0.59, normality goes from p = 0.002 to p = 0.48, and the slope 0.331 is the species–area exponent z. The transformation works.

So why is there anything left to teach? Run this:

▶ Type this yourself:

c(arithmetic = mean(g_df$n_species),
  geometric  = exp(mean(log(g_df$n_species))))

✏️ Q6: Those two numbers are 119.3 and 73.6. lm() on a logged response back-transforms to the second one. Which of the two did you think you were modelling?

✏️ Q7: No island here has zero species. Suppose one did. What does log10(0) return, and what would you have to do to the data to carry on?

✏️ Q8: A count is a whole number. log10(n_species) is not. Is that a problem in practice here — and can you say why it is more of a problem for small counts than large ones?

💡 Key idea: the transformation is not wrong, it is a different question. lm(log(Y) ~ X) models the mean of the log; a GLM with a log link models the log of the mean. Those back-transform to the geometric and the arithmetic mean — 73.6 against 119.3 here. Hold that thought; it explains a number in section 5.

🧩 Block 2 — Three families, one question (after lecture Parts 2–4)

Sections 4–7: Gaussian (the sanity check), Poisson (fails), negative binomial (works).

Section 4 · A Gaussian GLM is the same linear model

Before trusting glm() with an unfamiliar distribution, check that it reproduces the one you already know.

🔮 Predict first: a Gaussian GLM with an identity link is a linear model. Will the coefficients be identical, or just similar?

▶ Type this yourself:

# ---- 4 A Gaussian GLM is the same linear model -----------
lm_model <- lm(n_species ~ log(area_km2), data = g_df)

gauss_model <- glm(n_species ~ log(area_km2), data = g_df,
                   family = gaussian(link = "identity"))

round(cbind(lm = coef(lm_model), glm = coef(gauss_model)), 6)

all.equal(coef(lm_model), coef(gauss_model))

Anova(gauss_model, type = "III", test = "F")

✏️ Q9: Identical, or just close? What did all.equal() return?

✏️ Q10: So if a Gaussian GLM is just lm() again, what is glm() actually adding? (What did you have to name in the glm() call that lm() never asked for?)

✏️ Q11: summary(gauss_model) reports a dispersion parameter. Compare it to the residual mean square from anova(lm_model). What is it?

💡 Key idea: lm() is the special case of glm() where the family is Gaussian and the link is the identity. Everything that follows changes exactly those two arguments. You are not learning a new model — you are learning two knobs on the one you already have.

Section 5 · Poisson GLM — the obvious choice, and it fails

Poisson is the distribution for counts. It has only one parameter, which means its mean and its variance are forced to be the same number. Remember the ratio from Q2.

🔮 Predict first: the Poisson insists variance = mean. Your ratio was over 100. Will the overdispersion check come back clean?

▶ Type this yourself:

# ---- 5 Poisson GLM - the obvious choice, and it fails ----
poiss_model <- glm(n_species ~ log(area_km2), data = g_df,
                   family = poisson(link = "log"))

summary(poiss_model)

Anova(poiss_model, type = "III", test = "LR")

A Poisson GLM cannot use an F-test — the variance is pinned to the mean, so there is no \(\sigma^2\) to put in the denominator. We use a likelihood ratio test instead.

✏️ Q12: The slope is 0.2875. In section 3 the log–log slope was 0.331. Both are “the log slope” and they are different numbers. Which quantity is each one about?

✏️ Q13: \(e^{0.2875} = 1.333\). Finish this sentence: “every e-fold increase in island area multiplies expected richness by …”. Now do it for a doubling of area (\(2^{0.2875}\)).

✏️ Q15: Look at the DHARMa Q-Q plot. Which three tests printed on it are significant?

✏️ Q16: shapiro.test(residuals(poiss_model)) will run and give you a number. Why is that number meaningless?

💡 Key idea: R will not stop you from running a test that does not apply to the model you fitted. Check the diagnostic that matches the model, not the one you learned first.

Section 7 · Negative binomial — the one that works

The negative binomial adds a second parameter, theta (θ), which lets the variance exceed the mean: \(\operatorname{Var}(Y) = \mu + \mu^2/\theta\).

▶ Type this yourself:

# ---- 7 Negative binomial - the one that works ------------
nb_model <- glm.nb(n_species ~ log(area_km2), data = g_df)

summary(nb_model)

c(theta = nb_model$theta)

check_overdispersion(nb_model)

Anova(nb_model, type = "III", test = "LR")

AIC(poiss_model, nb_model)

▶ Type this yourself — put the two sets of standard errors side by side:

cbind(estimate   = round(coef(poiss_model), 4),
      SE_poisson = round(summary(poiss_model)$coefficients[, 2], 4),
      SE_negbin  = round(summary(nb_model)$coefficients[, 2], 4))

✏️ Q17: Compare the two slopes, then the two standard errors. Which barely moved, and which moved six-fold?

✏️ Q18: The Poisson LR χ² was about 979; the negative binomial’s is about 24. Did the conclusion change? Did the honesty of it change?

✏️ Q19: AIC drops by nearly 500. Nothing was added to the model but permission for the variance to be bigger than the mean. What does that tell you about how badly the Poisson was fitting?

✏️ Q20: Draw the fit: plot n_species against area_km2 on a log x-axis and add the NB fit. Why is the fitted line a curve on the raw count scale — the distribution, or the link?

🧩 Block 4 — A binary response (after lecture Parts 5–6)

Section 9 · Logistic regression

A count was one kind of non-normal response. A yes/no is another. Logistic regression models the probability of a 1, using the logit link to stretch probability (stuck between 0 and 1) onto a scale that runs from −∞ to +∞:

\[\log\left(\frac{\pi}{1-\pi}\right) = \beta_0 + \beta_1 x\]

Whitlock & Schluter’s guppy experiment: 160 guppies were each held at a cold temperature for one of four durations, and whether the fish died was recorded. mortality is 1 for died, 0 for survived; exposure_min is the duration in minutes.

Written for you in the skeleton:

# ---- 9 Logistic regression -------------------------------
guppy_df <- read_csv("data/guppy_cold_death.csv")

guppy_df %>%
  count(exposure_min, mortality) %>%
  pivot_wider(names_from = mortality, values_from = n,
              names_prefix = "mortality_")

▶ Type this yourself:

ggplot(guppy_df, aes(x = exposure_min, y = mortality)) +
  geom_jitter(height = 0.03, width = 0.3)

🔮 Predict first: longer in the cold is worse for a fish. Will the slope be positive or negative?

▶ Type this yourself:

guppy_model <- glm(mortality ~ exposure_min, data = guppy_df,
                   family = binomial(link = "logit"))

summary(guppy_model)

▶ Type this yourself — the likelihood ratio test, against a model with no predictor:

null_model <- glm(mortality ~ 1, data = guppy_df,
                  family = binomial(link = "logit"))

anova(null_model, guppy_model, test = "Chisq")

▶ Type this yourself — the odds ratio, three ways:

exp(coef(guppy_model))
exp(confint(guppy_model, "exposure_min"))

model_parameters(guppy_model, exponentiate = TRUE)

tidy(guppy_model, exponentiate = TRUE, conf.int = TRUE)

▶ Type this yourself — goodness of fit:

r2(guppy_model)

pR2(guppy_model)

hoslem.test(guppy_model$y, fitted(guppy_model), g = 4)

▶ Type this yourself — the fitted probability curve:

pred_df <- data.frame(
  exposure_min = seq(min(guppy_df$exposure_min),
                     max(guppy_df$exposure_min), length.out = 100)
)

pred_df$prob <- predict(guppy_model, newdata = pred_df, type = "response")

ggplot() +
  geom_jitter(data = guppy_df, aes(x = exposure_min, y = mortality),
              height = 0.03, width = 0.3) +
  geom_line(data = pred_df, aes(x = exposure_min, y = prob))

▶ Type this yourself — the dose at which half the fish die (LD50):

-coef(guppy_model)[1] / coef(guppy_model)[2]
