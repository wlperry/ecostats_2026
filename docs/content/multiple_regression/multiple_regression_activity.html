Activity: Multiple Regression

Several predictors

In-class activity on Loyn’s Victorian forest-bird data: fit predictors alone and together, diagnose collinearity, simplify the model, and set a factor’s reference level with fct_relevel().
Author

Bill Perry

Worksheet: Multiple Regression

📥 Bird data 📥 Tools script (.R) 📥 Script skeleton (.R)

The lecture’s dataset: 56 remnant forest patches in Victoria, Australia, from Loyn (1987). Bird abundance is the response, and six patch characteristics are the candidate predictors.

You will do four things, in this order: fit the predictors one at a time, fit them all at once and see what happens, work out why it happened, and then decide what to keep.

Part 1 · Setup and the data

▶ Run this:

# ── Part 1.1 · Setup and the data ───────────────────────────────────────

library(car)

source("themes_functions/r_themes_and_functions.R")

  mutate(log_area        = log10(area_ha),
         log_dist        = log10(dist_m),
         log_dist_larger = log10(dist_larger_m))

bird_df

Part 5 · Simplify the model

▶ Run this — drop the four predictors that earned nothing, then test whether dropping them cost anything:

# ── Part 5.1 · Simplify the model ───────────────────────────────────────
reduced_model <- lm(abundance ~ log_area + grazing, data = bird_df)

anova(reduced_model, full_model)

▶ Run this — compare the two models the other way:

# ── Part 5.2 · Simplify the model ───────────────────────────────────────
tibble(
  model  = c("six predictors", "log_area + grazing"),
  adj_r2 = c(summary(full_model)$adj.r.squared,
             summary(reduced_model)$adj.r.squared),
  AIC    = c(AIC(full_model), AIC(reduced_model))
)

Part 7 · Grazing as a factor

Grazing has been a number, 1 to 5, which forces every step to cost the same. Now let it be a category so each level is estimated separately.

▶ Run this — make it a factor and look at the order R chose:

# ── Part 7.1 · Grazing as a factor ──────────────────────────────────────
bird_df <- bird_df %>%
  mutate(grazing_class = factor(grazing_class))

levels(bird_df$grazing_class)

summary(lm(abundance ~ log_area + grazing_class, data = bird_df))

✏️ Your turn: Which level is R using as the reference, and why did it pick that one?

Reference level: __________   Why: _________________________

▶ Run this — put the least-grazed level first instead:

# ── Part 7.2 · Grazing as a factor ──────────────────────────────────────
bird_df <- bird_df %>%
  mutate(grazing_class = fct_relevel(grazing_class,
                                     "minimal", "light", "moderate",
                                     "heavy", "intense"))

levels(bird_df$grazing_class)

grazing_model <- lm(abundance ~ log_area + grazing_class, data = bird_df)

summary(grazing_model)

Part 8 · The figure you hand in

# ── Part 8.1 · The figure you hand in ───────────────────────────────────
final_plot <- ggplot(bird_df, aes(log_area, abundance,
                                  colour = grazing_class)) +
  geom_point(size = 2.5) +
  geom_smooth(method = "lm", se = FALSE) +
  labs(
    title = "Bird abundance rises with patch area and falls under intense grazing",
    subtitle = "56 remnant forest patches, Victoria, Australia (Loyn 1987)",
    x = "log10 patch area (ha)",
    y = "Bird abundance",
    colour = "Grazing"
  ) +
  theme_regular(base_size = 12)
