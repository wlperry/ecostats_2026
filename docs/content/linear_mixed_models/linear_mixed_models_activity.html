Activity: Linear Mixed Models

Random effects for nested data

Hands-on activity: fitting the sea urchin nested design with lme4::lmer(), reading the patch and residual variances, using the ICC to see what the next experiment needs, testing the treatment with the F-test, and making the final figure. Then two more designs: chick growth through time with random slopes, and a simulated stream experiment blocked by stream.
Author

In-class Activity 16: Linear Mixed Models

Today’s Objectives

  3. Use the ICC to say how much patches matter, and what the next experiment needs

Where this fits

16 patches of reef each got one urchin density. 5 quadrats were scored in every patch. The treatment was applied to the patch, so there are 16 real replicates, not 80. In lecture, ignoring that gave p = 0.00003; testing the treatment against patches gave p = 0.091.

A mixed model handles this by naming patch as a random effect.

Fixed effect Random effect
What it is levels you chose levels sampled from many
What you want the difference between them how much they vary
Here treat, the four densities patch, 16 bits of reef

R will print two variances. We call them by R’s names:

  • patch variance: how much patches differ from their own treatment’s mean (among-patch)
  • residual variance: how much quadrats differ from their own patch’s mean (within-patch)

🧩 Block 1: Fit the model and read it (after lecture Parts 1–2)

Section 1 · The sea urchin data

Written for you in the skeleton. Run it and read it.

# ---- Libraries -------------------------------------------
library(janitor)
library(car)          # Anova()
library(lme4)         # lmer()
library(lmerTest)     # df and p-values for lmer
library(emmeans)
library(performance)  # icc()
library(DHARMa)
library(tidyverse)

options(scipen = 999)
options(contrasts = c("contr.sum", "contr.poly"))  # for Anova(type = 3)
# ---- 1 The sea urchin data -------------------------------
u_df <- read_csv("data/andrew.csv") %>%
  clean_names() %>%
  mutate(
    treat = case_when(
      treat == "removal" ~ "0%",
      treat == "dens_66" ~ "33%",
      treat == "dens_33" ~ "66%",
      treat == "control" ~ "100%"
    ),
    treat = factor(treat, levels = c("0%", "33%", "66%", "100%")),
    patch = as_factor(patch)
  )

head(u_df)

✏️ Q1: What was the treatment applied to: a quadrat or a patch? So how many real replicates are there?

Section 2 · Fit the mixed model and read the output

▶ Type this yourself:

# ---- 2 Fit the mixed model -------------------------------
mixed_model <- lmer(algae ~ treat + (1 | patch), data = u_df,
                    control = lmerControl(calc.derivs = FALSE))

summary(mixed_model)

(1 | patch) gives each patch its own baseline: a random intercept. calc.derivs = FALSE just skips a noisy convergence check.

Find the Random effects block:

 Groups   Name        Variance Std.Dev.
 patch    (Intercept) ...
 Residual             ...

✏️ Q2: Write down the patch variance and the residual variance. Which is bigger, or are they about the same?

✏️ Q3: The output says Number of obs: 80, groups: patch, 16. Which number is the real replication for testing treat?

✏️ Q4: Why is patch random and treat fixed? (Hint: would a repeat of the study use the same patches? The same densities?)

💡 Skip the Fixed effects table in summary(). With contr.sum, treat1, treat2 and so on are deviations from the grand mean, which is confusing. You will get the treatment means from emmeans() in section 5.

🧩 Block 2: How much do patches matter? (after lecture Part 3)

Section 3 · The ICC

🔮 Predict first: the four patches with urchins removed have means of 34, 62, 2 and 58% algae. Is more of the variation among patches, or among quadrats within a patch?

▶ Type this yourself:

# ---- 3 The ICC -------------------------------------------
icc(mixed_model)

The ICC is

\[ICC = \frac{\text{patch variance}}{\text{patch variance} + \text{residual variance}}\]

the share of the variation that is among patches. Use the adjusted ICC.

✏️ Q5: Check it by hand from your Q2 numbers. Do you get the same value?

✏️ Q6: Finish this sentence about the reef: “About % of the differences in algae cover come from .”

✏️ Q7: An ICC near 0 would mean what about the patches? Near 1?

✏️ Q8: Next year you can afford either twice as many quadrats per patch or twice as many patches. Which one helps more, and why? (Think about patch 15, which was nearly bare.)

▶ Type this yourself: R², how much of the variation each part explains:

r2(mixed_model)

A mixed model gets two R² values:

  • Marginal R²: explained by the fixed effects only (treat)
  • Conditional R²: explained by fixed and random effects (treat + patch)

✏️ Q8b: What share of the variation in algae cover does the treatment explain? What share do treatment and patch explain together? So what share is due to patches alone (conditional − marginal)?

✏️ Q8c: Which explains more of the variation: urchin density or which patch a quadrat was in? Why would reporting only “R² = 0.62” be misleading?

🧩 Block 3: Test, means and checks (after lecture Part 4)

Section 4 · Test the treatment

▶ Type this yourself:

# ---- 4 Test the treatment --------------------------------
Anova(mixed_model, type = 3, test.statistic = "F")

Anova(mixed_model, type = 3, test.statistic = "Chisq")

✏️ Q9: Write down the p-value from each. Which side of 0.05 does each fall on?

✏️ Q10: The F-test’s denominator df is 12. Where does 12 come from? (Patches, treatments.)

✏️ Q11: The chi-square test assumes you have infinite replicates. You have 16 patches. Which test do you report?

💡 Key idea: with few groups, which is nearly always the case in ecology, report the F-test (Kenward-Roger df). The chi-square is over-confident, and if you had run only that one you would have reported a “significant” effect and never known.

Section 5 · Treatment means

▶ Type this yourself:

# ---- 5 Treatment means -----------------------------------
emm <- emmeans(mixed_model, ~ treat)
emm

pairs(emm, adjust = "sidak")

✏️ Q12: What is the mean algae cover with urchins removed (0%) and at natural density (100%)? Is that a big difference?

✏️ Q13: Some confidence limits go below zero. Algae cover can’t be negative. What is the model assuming that isn’t true? (Last week’s lecture has the fix.)

Section 6 · Diagnostics

▶ Type this yourself:

# ---- 6 Diagnostics ---------------------------------------
set.seed(123)
sim_mixed <- simulateResiduals(mixed_model, plot = FALSE)

plotQQunif(sim_mixed)
plotResiduals(sim_mixed)

✏️ Q14: Do the plots look acceptable, roughly? Percent cover with lots of zeros won’t be perfect. What would you say in a methods section?

✏️ Q21: The diet was given to a chick. How many chicks are there, and how many rows? Which is the replication for a diet effect? Do the lines run parallel or fan out?

ck_lm <- lm(weight ~ time * diet, data = ck_df)

Section 10 · A treatment blocked by stream

These data are simulated. 3 streams; in each a reference reach, a crack willow reach, and a reach where willow was removed. 15 samples per reach. The truth is known: willow cuts insect numbers by 30%.

Written for you in the skeleton. Run it and look at the plot.

# ---- 10 A treatment blocked by stream --------------------
w_df <- read_csv("data/willow_streams_simulated.csv") %>%
  mutate(
    reach = factor(reach, levels = c("reference", "willow", "removed")),
    stream = factor(stream),
    log_insects = log(insects)
  )

w_means <- w_df %>%
  group_by(stream, reach) %>%
  summarise(log_insects = mean(log_insects), .groups = "drop")

ggplot(w_df, aes(x = reach, y = log_insects)) +
  geom_point() +
  geom_line(data = w_means, aes(group = stream)) +
  facet_wrap(~ stream)

✏️ Q25: What was the treatment applied to: a sample, a reach or a stream? How many of each kind are there?

▶ Type this yourself: the wrong way and the right way:

w_naive <- lm(log_insects ~ reach, data = w_df)
w_mixed <- lmer(log_insects ~ reach + (1 | stream) + (1 | stream:reach),
                data = w_df,
                control = lmerControl(calc.derivs = FALSE))

anova(w_naive)
anova(w_mixed)

✏️ Q26: Denominator df and p for reach in each. Why is (1 | stream:reach) the urchin (1 | patch) under another name?

✏️ Q27: The effect was real and the mixed model gave p ≈ 0.10. A lab-mate suggests 30 samples per reach next year instead of 15. Is that the right fix? What would you do instead?

💡 Key idea: before fitting anything, ask what the treatment was applied to and count those. That number, not the number of rows, is your replication.
