Worksheet: T-Tests — One, Two, Paired

📥 Data (.csv) 📥 Data (.xlsx) 📥 Tools script (.R) 📥 Script skeleton (.R)

How to use this worksheet

There are four sections:

  1. Read in the data and look at it — all 64 needles first, then the 8 tree means. No tests, just plots
  2. One-sample t-test — is one group different from a fixed number? (plus the one-tailed variation)
  3. Two-sample t-test — are the two sides different from each other?
  4. Paired t-test — is each tree different on its two sides?

Work through them in order. Type every line of code yourself into the script skeleton — do not copy-paste from this worksheet. Blocks marked ▶ Run this are code you type and execute. Blocks marked ✏️ Your turn are for you to write in, by hand, on this sheet.

Before you start: download the script skeleton from the button above and save it as 06_T_tests.R in your project’s scripts/ folder. It already has the # ── Part … headers laid out in order, and the blocks you have typed a dozen times — setup, reading the data, averaging away pseudoreplication, the summarize() block — are filled in for you. Everything else is blank, and that blank space is the lesson. Work down the worksheet and type your code under the matching header.

Type the # ── Part … header comment at the top of each block, too. Those comment lines are not decoration — they are how your script stays navigable, how you find your way back to a block that broke, and how I find your work when I read your script.

The code here is deliberately bare. No titles, no axis labels, no legends, no colours. That is not an oversight — it is so you can see what each line actually does. Once a plot works, dress it up however you like.

1.4 · Average out the pseudoreplication

The 8 needles from one side of one tree are pseudoreplicates — they are not 8 independent measurements, they are 8 looks at the same tree side. Average them so each tree side is one data point.

▶ Run this:

  group_by(team, side) %>%
  summarise(needle_length_mm = mean(needle_length_mm, na.rm = TRUE),
            .groups = "drop")

⚠️ Watch out! 64 rows became 8. That is not data loss — it is the correct sample size. We measured 8 needles per side, but only 4 trees.

ImportantDegrees of freedom — read this before Sections 2, 3 and 4

df = the number of values free to vary once you have estimated a mean. You lose one df for every mean you estimate. Our data is 4 trees, one shady side and one sunny side each — so n is always trees, never needles.

Test What n counts df formula Our df
One-sample (Section 2) trees in the one group n − 1 3
Two-sample (Section 3) trees in both groups n₁ + n₂ − 2 6
Welch’s (Section 3) both groups, penalised Welch–Satterthwaite ≈ 5.66
Paired (Section 4) differences npairs − 1 3

Check the df = line in every bit of t.test() output below against this table. If it does not match, you ran a different test than you thought you did.

⚠️ Watch out! Choosing the tail after looking at your means is not a one-tailed test. It is a two-tailed test with the p-value secretly halved, and it is one of the most common ways people accidentally cheat. Pick the direction from the biology, before you collect data, or use two-tailed.

Tip

🚀 If you finish early: A one-tailed test is defensible when a result in the opposite direction would lead to the same action as no result at all — a drug that harms patients and a drug that does nothing are both “do not approve.” For our pine needles, is “sunny is longer” and “shady is longer” both interesting biology? Tip

🚀 If you finish early — compute the t-statistic by hand and confirm it matches t.test():

\[t = \frac{\bar{x}_1 - \bar{x}_2}{S_p\sqrt{\frac{1}{n_1} + \frac{1}{n_2}}}\]

# ── Part 3.6 · Two-sample t by hand ─────────────────────────────────────
sunny_df <- p_df %>% filter(side == "sunny")   # shady_df is from Part 2.1

n1 <- length(shady_df$needle_length_mm)
n2 <- length(sunny_df$needle_length_mm)
s1 <- sd(shady_df$needle_length_mm)
s2 <- sd(sunny_df$needle_length_mm)

sp <- sqrt(((n1 - 1) * s1^2 + (n2 - 1) * s2^2) / (n1 + n2 - 2))

(mean(shady_df$needle_length_mm) - mean(sunny_df$needle_length_mm)) /
  (sp * sqrt(1/n1 + 1/n2))

Look at the denominator of sp: n1 + n2 - 2. That is the degrees of freedom. df is not a rule to memorise — it is whatever you divided by.
