Part 2 · Hypothesis Testing Framework

Hypothesis Testing — the Key Components

Every test you will ever run starts with the same five lines, in this order, written down before you look at the output:

  1. Question — the biology, in plain English. Does the sunny side of a pine tree grow longer needles than the shady side?
  2. Prediction — what you expect to see, and why. Sunny needles will be longer, because more light means more photosynthate available for growth.
  3. Null hypothesis (H₀) — “no effect,” the thing the test actually evaluates. H₀: μsunny = μshady
  4. Alternative hypothesis (Hₐ) — what is true if H₀ is not. Hₐ: μsunny ≠ μshady
  5. Significance level (α) — your threshold, chosen up front. Typically α = 0.05.

Decision rule: reject H₀ if p < α.

Important

The prediction and the alternative are not the same thing

The prediction is directional and biological — sunny is longer. The alternative hypothesis here is two-tailed — they differ, either way.

If your prediction is genuinely directional and you commit to it beforehand, you can run a one-tailed test. Deciding that after seeing the data is cheating.

Note

📖 Reference

Gotelli & Ellison, A Primer of Ecological Statistics, Ch. 4 — Framing and Testing Hypotheses.

The Logic of a Statistical Test

A test assesses the likelihood of the null hypothesis being true.

  • If H₀ is likely false, Hₐ is assumed correct
  • More precisely: the long-run probability of obtaining our sample value (or a more extreme one) if the null hypothesis is true
  • Written p(data | H₀) — the probability of the data, given H₀
Important

✅ Key idea

p(data | H₀) is not the same as p(H₀ | data). A t-test never tells you the probability that H₀ is true — only how surprising your data would be if it were.

p-value Interpretation
p > 0.10 No evidence against H₀
0.05 – 0.10 Weak evidence against H₀
0.01 – 0.05 Moderate evidence against H₀
0.001 – 0.01 Strong evidence against H₀
p < 0.001 Very strong evidence against H₀

Part 3 · The t-Distribution

One-Tailed Questions

One-tailed questions ask about the area of the distribution to the left (or right) of a certain value.

Note

Table-reading example — not our data

A study with n = 8 has df = n − 1 = 7. That is the row highlighted in the table beside this slide, and the only reason 8 and 7 appear together here.

  • 95% of the observations fall to the left of t = 1.895
  • 5% fall outside, in the one tail

Two-Tailed Questions

Two-tailed questions refer to the area between certain values.

Same table-reading example — n = 8, so df = 7:

  • 95% of the observations lie between t = −2.365 and t = 2.365 (2.5% outside on each side)
  • Compare to the one-tailed cutoff: t = 1.895 (5% outside)
Tip

🖐 Notice

The two-tailed critical value is farther from zero than the one-tailed value
— splitting 5% into two tails means each tail only gets 2.5%.

✅ Key Idea · Degrees of Freedom, Once and For All

What df means: the number of values that were free to vary once you estimated a mean. Estimate one mean from n numbers and you spend one df — the last value is pinned down by the others.

So you lose one df for every mean you estimate.

Our data: 4 trees, one shady side and one sunny side each.

  • One-sample t-test — one group, one mean estimated df = n − 1 = 4 − 1 = 3 (4 shady tree means, compared to a fixed number like 15 mm)

  • Two-sample t-test — two groups, two means estimated df = n₁ + n₂ − 2 = 4 + 4 − 2 = 6 (8 tree means in total, minus one for each group mean)

  • Paired t-test — you first collapse each tree to one difference, then it is a one-sample test on those differences df = npairs − 1 = 4 − 1 = 3 (4 differences, not 8 values)

  • Welch’s t-test — the odd one out. df comes from the Welch–Satterthwaite equation, is usually not a whole number, and is always ≤ the Student’s df. Here: df ≈ 5.66.

Test What n counts df formula Our df
One-sample trees in the one group n − 1 3
Two-sample trees in both groups n₁ + n₂ − 2 6
Paired differences npairs − 1 3
Welch’s both groups, penalised Welch–Satterthwaite ≈ 5.66
Important

The number that keeps changing is not arbitrary

n is always trees, never needles. What changes is how many means you had to estimate to run the test.

The paired test has half the df of the two-sample test on the identical 8 numbers — because it only ever looks at 4 numbers, the differences.

Calculating a Confidence Interval

Using a two-sided test:

\[\text{CI} = \bar{y} \pm t_{0.975,\,df} \cdot \frac{s}{\sqrt{n}}\]

Our own shady-side trees — n = 4, so df = 3:

n_shady    <- sum(!is.na(shady_df$needle_length_mm))
mean_shady <- mean(shady_df$needle_length_mm)
se_shady   <- sd(shady_df$needle_length_mm) / sqrt(n_shady)
t_crit     <- qt(0.975, df = n_shady - 1)

mean_shady + c(-1, 1) * t_crit * se_shady
[1] 10.91210 17.32978

And the same interval, for free, from the function we sourced:

summary_stats(shady_df$needle_length_mm)
# A tibble: 1 × 6
      n  mean    sd    se ci_lower ci_upper
  <int> <dbl> <dbl> <dbl>    <dbl>    <dbl>
1     4  14.1  2.02  1.01     10.9     17.3
Warning

⚠️ Four trees is a wide interval

With df = 3 the critical t is 3.182, not 1.96 and not the 2.365 highlighted in the table image (that is df = 7).

Small n costs you twice: a bigger multiplier and a bigger standard error.

Applications of the t-Distribution

  • Can assess confidence that the population mean is within a certain range
  • Can use the t-distribution to ask:
    • “What is the probability of getting a sample with mean = ȳ from a population with mean = µ?” (1-sample t-test, df = n − 1)
    • “What is the probability that two samples came from the same population?” (2-sample t-test, df = n₁ + n₂ − 2)
    • “Is the average change within a subject different from zero?” (paired t-test, df = npairs − 1)
Tip

🖐 Try it yourself

Before the next slide: which of these three questions does our pine needle design actually ask?

Part 4 · One-Sample T-Test

One-Sample T-Test — Question, Prediction, Hypotheses

Question: Is the mean needle length on the shady side different from the 15 mm reported for this species?

Prediction: Shady needles are shorter than 15 mm, because they are light-limited.

  • H₀: μ = 15 mm
  • Hₐ: μ ≠ 15 mm (two-tailed)
  • α = 0.05

Assumptions for a t-test:

  1. Data are normally distributed
  2. Observations are independent
  3. No significant outliers
Note

✅ Degrees of freedom here

One group — the 4 shady tree means. One mean estimated.

df = n − 1 = 4 − 1 = 3

Note

📖 Reference

Whitlock & Schluter, Ch. 11, covers the one-sample t-test as the simplest hypothesis test on a normally distributed variable.

Checking Normality — QQ Plot

# The one-sample test is on the SHADY side, so that is the group
# whose normality we check -- not the two sides pooled.
qqPlot(shady_df$needle_length_mm)
[1] 4 1
# The base R version -- same idea, no packages, no envelope
qqnorm(shady_df$needle_length_mm)
qqline(shady_df$needle_length_mm)
Tip

🖐 Notice

Points that hug the line support normality; points that curve away — especially in the tails — are a warning sign.

qqPlot() from car adds a shaded confidence envelope; base R’s qqnorm() + qqline() gives you the same picture without it. Either is fine.

Warning

⚠️ With 4 points, this is a sanity check, not proof

Four points will look “fine” on almost any QQ plot.

Checking Normality — Shapiro-Wilk Test

shapiro.test(shady_df$needle_length_mm)

    Shapiro-Wilk normality test

data:  shady_df$needle_length_mm
W = 0.94326, p-value = 0.6743
Important

H₀ for Shapiro-Wilk is “the data ARE normal.” A non-significant result (p > 0.05) is what we’re hoping for — it means we fail to reject normality.

Warning

⚠️ With n = 4, this test proves almost nothing

Shapiro-Wilk on four numbers has essentially no power — it will pass almost anything. A high p-value here is not evidence that the data are normal; it is evidence that we don’t have enough data to tell.

Run it, report it, but lean on the QQ plot, the biology, and the design.

Tip

🖐 Why the shady side only?

We test the group the hypothesis is about. Pooling shady and sunny would mix two distributions with different means, which can look non-normal even when each group is perfectly normal.

One-Tailed Variation — the Same Test, One Direction

Our prediction was directional: shady needles are shorter than 15 mm. If we commit to that before collecting data, we can run a one-tailed test.

  • H₀: μ ≥ 15
  • Hₐ: μ < 15 — all 5% of α in the lower tail
one_tailed_model <- t.test(shady_df$needle_length_mm,
                           mu = 15,
                           alternative = "less")

Compare the two p-values:

Test Hₐ p
Two-tailed μ ≠ 15 0.448
One-tailed μ < 15 0.224

Exactly half. All of α now sits in one tail, so the observed t only has to beat one cutoff instead of two.

Warning

⚠️ Notice the confidence interval changed too

It now runs from −Inf to an upper bound. A one-tailed test makes no claim in the direction you ruled out.

One-Tailed vs. Two-Tailed — What It Costs You

Remember the critical values from Part 3. At df = 3:

qt(0.975, df = 3)   # two-tailed, 2.5% in each tail
[1] 3.182446
qt(0.95,  df = 3)   # one-tailed, 5% in one tail
[1] 2.353363

The one-tailed cutoff (2.353) is closer to zero than the two-tailed cutoff (3.182). That is the extra power — a smaller t will do.

But run it the other way and watch what happens:

t.test(shady_df$needle_length_mm, mu = 15,
       alternative = "greater")

    One Sample t-test

data:  shady_df$needle_length_mm
t = -0.87183, df = 3, p-value = 0.7763
alternative hypothesis: true mean is greater than 15
95 percent confidence interval:
 11.74806      Inf
sample estimates:
mean of x 
 14.12094

Same data, same t = −0.87, and now p = 0.776.

Important

⚠️ The rule that makes one-tailed tests honest

You must pick the direction before you see the data, on biological grounds, and you must accept that a result in the other direction tells you nothing — no matter how big it is.

Choosing the tail after looking at your means is not a one-tailed test. It is a two-tailed test with the p-value secretly halved.

Tip

🖐 When is one-tailed defensible?

When the opposite result would lead to the same action as no result. A drug that makes patients worse and a drug that does nothing are both “do not approve.”

For our pine needles, “sunny is longer” and “shady is longer” are both interesting biology. Two-tailed is the honest default.

Interpreting the One-Sample T-Test

Activity: interpret the t-test results

  • What does the p-value tell us?
  • Should we reject or fail to reject the null hypothesis?
  • Does the 95% CI from summary_stats() contain 15 mm — and does that agree with the p-value?

Two things you must always report: the degrees of freedom, in parentheses after t, and whether the test was one- or two-tailed.

Part 5 · Two-Sample T-Test

Two-Sample T-Tests — the Question

Question: Do needles differ in length between the sunny and shady sides?

Prediction: Sunny needles are longer — more light, more growth.

  • H₀: μshady = μsunny
  • Hₐ: μshady ≠ μsunny (direction not specified)
  • α = 0.05

A two-sample t-test compares means from two independent groups.

Note

✅ Degrees of freedom here

Two groups, two means estimated from 8 tree means.

df = n₁ + n₂ − 2 = 4 + 4 − 2 = 6

Two-Sample T-Test Framework

\[t = \frac{\bar{x}_1 - \bar{x}_2}{S_p\sqrt{\frac{1}{n_1} + \frac{1}{n_2}}} = \frac{\text{SIGNAL}}{\text{NOISE}}\]

Where:

  • x̄₁, x̄₂: sample means of the two groups
  • s²ₚ: pooled variance = [(n₁−1)s₁² + (n₂−1)s₂²] / (n₁+n₂−2)
  • Sₚ = √s²ₚ: the pooled standard deviation
  • Sₚ√(1/n₁ + 1/n₂): the standard error of the difference — the whole denominator
Important

The df is sitting right inside the formula

Look at the denominator of the pooled variance: n₁ + n₂ − 2. That is the degrees of freedom. It is the divisor that turns two sums of squares into one variance estimate, and the same number then indexes the t-distribution you compare your t to.

df is not a rule to memorise — it is whatever you divided by.

Note

📖 Reference

Whitlock & Schluter, Ch. 12 — Comparing Two Means.

Important

H₀ for Levene’s test is “the variances are equal.”

You want a non-significant result. If p > 0.05, the standard (Student’s) t-test is fine. If p < 0.05, use Welch’s.

leveneTest() needs the grouping variable as a factor.

Conducting the Two-Sample T-Test

Standard (Student’s) — equal variances

                           data = p_df, var.equal = TRUE)

Standard vs. Welch’s t-Test

Standard t-test (Student’s)

  • Assumes equal variances between groups
  • Uses a pooled variance estimate combining both groups
  • Higher power when the equal-variance assumption is met
  • df = n₁ + n₂ − 2 = 6 — a whole number, every time

Welch’s t-test

  • Does not assume equal variances
  • Uses separate variance estimates for each group
  • More robust when group variances differ
  • df from the Welch–Satterthwaite equation — typically not a whole number, and always smaller than n₁ + n₂ − 2. Here df ≈ 5.66
Tip

🖐 The fractional df is the price of the robustness — Welch’s buys safety by spending degrees of freedom.

Part 6 · Paired T-Test

What Does a Paired T-Test Tell Us?

Paired t-test:

  • Compares two measurements from the same subject or matched pair
  • Tests whether the mean difference between paired observations equals zero
  • Uses the differences between pairs as the data
  • Generally more powerful, because it removes subject-to-subject variation from the noise
Note

✅ Degrees of freedom here

4 trees → 4 differences → one mean difference estimated.

df = npairs − 1 = 4 − 1 = 3

Not 6. The 8 numbers became 4 the moment you subtracted.

Warning

⚠️ Order matters for the sign

t.test(shady, sunny, paired = TRUE) computes shady − sunny. Reverse the arguments and t flips sign — the p-value is identical, but the direction you report is backwards.

p_wide_df <- p_df %>%
  pivot_wider(names_from = side,
              values_from = needle_length_mm)

Same Data, Two Different Answers

Both tests used exactly the same 8 numbers, and both measured shady − sunny:

Test t df p
Two-sample −0.855 6 0.425
Paired −2.723 3 0.072

Same estimated difference (−1.09 mm, shady needles shorter). Same data. The p-value dropped by a factor of almost six.

Why?

  • The two-sample test throws the pairing away. Tree-to-tree variation (some teams’ trees just have longer needles) lands in the noise, swamping the signal.
  • The paired test looks only at the shady − sunny difference within each tree, so tree-to-tree variation cancels out entirely.
Important

And notice it did that on half the degrees of freedom

3 instead of 6 — because it is working with 4 differences, not 8 values. A smaller df makes significance harder to reach. It still won by a mile, because the noise it removed mattered far more than the df it gave up.

Note

These data are paired by design — each team measured both sides of the same tree. The two-sample test is not just less powerful, it is answering a question our design never asked.

slope_plot

Each line is one tree. All four shift the same way — that consistency is exactly what the paired test measures and the two-sample test cannot see.

✅ A Paired Test Is a One-Sample Test

Here is the idea that makes the df finally click. Treat the shady side as each tree’s own control, and compute one difference per tree:

diff_df <- p_wide_df %>%
  mutate(difference = sunny - shady)

Important

Identical. Same t, same df, same p.

t.test(sunny, shady, paired = TRUE) and t.test(sunny - shady, mu = 0) are the same test. paired = TRUE is nothing more than a convenience that does the subtraction for you.

That is why the paired df is npairs − 1 = 3 and not n₁ + n₂ − 2 = 6: once you subtract, you genuinely only have four numbers. A one-sample test on four numbers has 3 df. Always.

Tip

🖐 Each tree is its own control

The shady side accounts for everything about that particular tree — its genetics, its soil, its water, its team’s measuring technique. Subtracting removes all of it at once, and what is left is the effect of sun.

This is the same logic as a before/after design, and it is the seed of the blocked designs you will meet in ANOVA.

Part 7 · Assumptions and Wrap-Up

Assumptions of Parametric Tests

Common assumptions for t-tests:

  1. Normality — the data (or, for a paired test, the differences) come from a normally distributed population
  2. Equal variances — two-sample tests only
  3. Independence — observations are independent
  4. No outliers — extreme values can dominate a small sample

What do we do if our data violate these?

Alternatives when assumptions are violated:

  • Data transformation (log, square root)
  • Non-parametric tests — Mann-Whitney U for two samples, Wilcoxon signed-rank for paired
  • Robust methods
Tip

🖐 Note the paired case

You check normality of the differences, not of the two groups. Which follows directly from the last slide — the differences are the data.
