Activity: Multivariate Statistics

Distance and ordination

Hands-on activity: standardization, the dissimilarity matrix and why the choice of metric matters, a first PCA on Darlingtonia cobra lily morphology, a first Bray-Curtis NMDS on Doubs River fish counts, and testing group differences with PERMANOVA.
Author

Bill Perry

In-class Activity 18: Multivariate Statistics

Today’s Objectives

  1. Say why multivariate data cannot be handled one variable at a time
  2. Standardize a set of variables, and say when you should not
  3. Build a dissimilarity matrix and explain why it is the hub of everything downstream
  4. Choose between Euclidean, Manhattan, Bray–Curtis and Jaccard, and defend the choice
  5. Run a PCA, read a scree plot, and interpret loadings as biology
  6. Translate an arbitrary component sign into a correct sentence
  7. Run an NMDS on count data and read its stress
  8. Test group differences with PERMANOVA, and check its dispersion assumption

Block A · Data, standardization, and distance

After lecture Parts 1–3.

1 · Load and look

▶ Run this:

# ── Part 1.1 · Load the two datasets ────────────────────────────────────
darlingtonia <- read_csv("data/darlingtonia.csv")

doubs_spe <- read_csv("data/DoubsSpe.csv") %>% rename(site = 1)

# das is distance from the river's source, so it orders the
# sites upstream -> downstream. We cut it into three reaches.
doubs_env <- read_csv("data/DoubsEnv.csv") %>%
  rename(site = 1) %>%
  mutate(reach = factor(
    case_when(das <  100 ~ "Upstream",
              das <  250 ~ "Midstream",
              TRUE       ~ "Downstream"),
    levels = c("Upstream", "Midstream", "Downstream")))

darlingtonia %>% count(site)

▶ Run this — the raw variables, on their own scales:

# ── Part 1.2 · The scale problem, in a picture ──────────────────────────
darlingtonia %>%
  pivot_longer(-site, names_to = "variable", values_to = "value") %>%
  ggplot(aes(site, value, fill = site)) +
  geom_boxplot() +
  facet_wrap(~variable, scales = "free_y")
Note✏️ Q1

Which variable has the largest numbers? Which has the smallest? If you computed a distance on these raw values, which variable would decide the answer almost single-handedly?

2 · Standardize

▶ Run this:

# ── Part 2.1 · How bad is the scale problem? ────────────────────────────
darlingtonia %>%
  summarize(sd_height   = sd(height),
            sd_wingmass = sd(wingmass_g),
            ratio       = sd(height) / sd(wingmass_g))

▶ Run this — z-score every variable:

# ── Part 2.2 · Standardize ──────────────────────────────────────────────
darl_numeric <- darlingtonia %>% dplyr::select(-site)

darl_scaled <- scale(darl_numeric)

round(colMeans(darl_scaled), 3)
round(apply(darl_scaled, 2, sd), 3)
Note✏️ Q2

The means came back as 0 and the SDs as 1 — by construction, not by luck. So what information did standardizing destroy, and why are we willing to lose it here?

3 · Distance, and the choice of metric

▶ Run this — the distance between two plants, two ways:

# ── Part 3.1 · Euclidean distance between two objects ───────────────────
sqrt(sum((darl_scaled[1, ] - darl_scaled[2, ])^2))

as.matrix(dist(darl_scaled))[1, 2]

▶ Run this — the corner of the full dissimilarity matrix:

# ── Part 3.2 · The dissimilarity matrix ─────────────────────────────────
d_darl <- dist(darl_scaled)

round(as.matrix(d_darl)[1:5, 1:5], 2)
Note✏️ Q3

The matrix is symmetric with zeros down the diagonal. Why must both of those be true? What would it mean if a diagonal entry were not zero?

▶ Run this — now the fish counts, which are a different animal entirely:

# ── Part 3.3 · Why community data is different ──────────────────────────
doubs_mat <- as.matrix(doubs_spe %>% dplyr::select(-site))

# what fraction of the table is zeros?
mean(doubs_mat == 0)

# sites 1 and 29 -- how many species does each hold?
rowSums(doubs_mat > 0)[c(1, 29)]

▶ Run this — the same pair of sites, under four metrics:

# ── Part 3.4 · Four metrics, one pair of sites ──────────────────────────
e <- as.matrix(vegdist(doubs_mat, method = "euclidean"))
m <- as.matrix(vegdist(doubs_mat, method = "manhattan"))
b <- as.matrix(vegdist(doubs_mat, method = "bray"))
j <- as.matrix(vegdist(doubs_mat > 0, method = "jaccard"))

c(euclidean = e[1, 29],
  manhattan = m[1, 29],
  bray      = b[1, 29],
  jaccard   = j[1, 29])
Note✏️ Q4

Sites 1 and 29 share no species at all. Bray–Curtis and Jaccard both return exactly 1.0. What does 1.0 mean on those scales, and why can Euclidean distance never give you that information?

Note✏️ Q5

Site 1 holds one species; site 29 holds 26. Most of the 27 species are absent from both. Euclidean distance treats every shared absence as a point of similarity. Give one ecological reason a species might be missing from a site that has nothing to do with the site resembling any other site.

Find the strongest correlation in the matrix. Does it make biological sense? Now find a pair that is close to zero — what does that pair tell you about the number of components you are likely to need?

Note✏️ Q7

Where is the elbow? How many components would you keep, and what is your cumulative percentage at that point? Would the Kaiser rule (eigenvalue > 1) give you the same answer? Check it:

sum(pca_result$sdev^2 > 1)

5 · Loadings, and the sign trap

▶ Run this:

# ── Part 5.1 · Loadings for the first three components ──────────────────
round(pca_result$rotation[, 1:3], 3)

▶ Run this — PC1, as a picture:

# ── Part 5.2 · PC1 loadings ─────────────────────────────────────────────
tibble(Variable = rownames(pca_result$rotation),
       Loading  = pca_result$rotation[, 1]) %>%
  ggplot(aes(reorder(Variable, Loading), Loading)) +
  geom_col(aes(fill = Loading > 0), show.legend = FALSE) +
  coord_flip() +
  geom_hline(yintercept = 0, linetype = "dashed")
Important⚠️ Before you write a word about PC1

Look at the sign of the loadings on your screen. If they are mostly negative, then a high PC1 score means a small plant. If they are mostly positive, a high score means a large one.

Either answer is correct — an eigenvector defines a line, and a line has no preferred end. What is not correct is writing “site X scores higher on PC1” and leaving it there. Translate it into biology first.

Note✏️ Q8

Write one sentence saying what a high PC1 score means for a cobra lily, in plain biological English, with the sign on your screen resolved. No component numbers in the sentence.

▶ Run this — the other two components:

Note✏️ Q9

PC2 and PC3 are each dominated by a small group of variables, not by all ten. Name the variables that dominate each, and give each component a two-word biological name.

8 · Testing group differences

▶ Run this — route 1, ANOVA on component scores:

# ── Part 8.1 · ANOVA on PC scores ───────────────────────────────────────
anova_pc1 <- aov(PC1 ~ site, data = pc_scores)
summary(anova_pc1)

multcomp::cld(emmeans(anova_pc1, ~ site), Letters = letters)

▶ Run this — route 2, PERMANOVA on the distance matrix:

# ── Part 8.2 · PERMANOVA ────────────────────────────────────────────────
adonis2(darl_scaled ~ site, data = darlingtonia, method = "euclidean")

▶ Run this — and its one real assumption:

# ── Part 8.3 · Dispersion ───────────────────────────────────────────────
disp <- betadisper(vegdist(darl_scaled, method = "euclidean"),
                   darlingtonia$site)

anova(disp)

round(tapply(disp$distances, darlingtonia$site, mean), 2)
Note✏️ Q14

PERMANOVA tested all ten variables at once; the ANOVA tested one component at a time. Name one thing each can tell you that the other cannot.

Note✏️ Q15

Is the dispersion test significant? Which site is the most variable around its own centroid? Given that result, how should you word the PERMANOVA conclusion so that it is honest?
