Part 2 · Two Ways to Be Wrong

Crossing the statistical decision against the unknown truth gives four outcomes: correct rejection, correct non-rejection, a Type I error (α) — a false positive — and a Type II error (β) — a false negative. Power = 1 − β.

Part 3 · What Is Power

Statistical power is the probability of detecting a true effect — of rejecting H₀ when it really is false. 80% power is the usual convention for an adequately powered study.

Part 4 · Effect Size — Cohen’s d

Cohen proposed rough benchmarks for small, medium, and large effects:

▶ Run this:

# ── Part 4.1 · Cohen's benchmarks ────────────────────────────────────
cohen.ES(test = "t", size = "small")$effect.size
cohen.ES(test = "t", size = "medium")$effect.size
cohen.ES(test = "t", size = "large")$effect.size

▶ Run this — the real Cohen’s d for both datasets:

# ── Part 4.2 · Cohen's d, pine and lizards ───────────────────────────
d_unpaired <- cohens_d(needle_length_mm ~ side, data = p_df)

d_paired

Part 5 · A Priori Power — Planning Before You Collect Data

The most useful power analysis happens before you collect data: guess or borrow an effect size, then ask what sample size gives 80% power.

▶ Run this:

# ── Part 5.1 · A priori power, pine (unpaired) ───────────────────────
pwr.t.test(
  d = d_unpaired$Cohens_d,
  power = 0.80,
  sig.level = 0.05,
  type = "two.sample"
)

✏️ Your turn: How many trees per side does that call for (always round n up)? How many did we actually collect?

Part 6 · Unequal Group Sizes — pwr.t2n.test()

The lizard groups are far from equal (154 living vs. 30 killed). pwr.t2n.test() takes the two actual group sizes directly — no averaging, no workaround.

▶ Run this:

# ── Part 6.1 · Power with unequal group sizes ────────────────────────
pwr.t2n.test(
  n1 = sum(lizard_df$survival == "living"),
  n2 = sum(lizard_df$survival == "killed"),
  d = d_lizard$Cohens_d,
  sig.level = 0.05
)

✏️ Your turn: What is the power? Compare it to the pine study’s power at n = 4 (you’ll compute that next, in Part 7).

Part 7 · Retrospective (Post-Hoc) Power

The other direction: after a study, ask what power your actual n and observed effect size gave you.

▶ Run this:

# ── Part 7.1 · Retrospective power, pine (unpaired) ──────────────────
pwr.t.test(
  n = 4,
  d = d_unpaired$Cohens_d,
  sig.level = 0.05,
  type = "two.sample"
)

Warning

⚠️ A warning about “post-hoc power”

Computing power from the effect size you observed is a known trap — it is fine for planning the next study, but it is not a valid way to explain away a non-significant result. “Our result was non-significant, but we had low power” says the same thing twice.

Part 9 · Error Bars — SD, SE, and CI

summary_stats() gives you all three from one call: SD (spread of the raw data), SE (precision of the mean, SD / sqrt(n)), and the 95% CI (plausible range for the true mean).

▶ Run this:

# ── Part 9.1 · SD, SE, and CI for the lizard data ────────────────────
lizard_df %>%
  group_by(survival) %>%
  reframe(summary_stats(squamosal_horn_length_mm))

✏️ Your turn: Which of the three (SD, SE, CI) is widest, and which is narrowest, for each group? A large sample doesn’t shrink SD — what does it shrink, and why?

Part 10 · Pseudoreplication

Pseudoreplication occurs when measurements that are not independent are analyzed as if they were — for example, treating every pine needle as an independent replicate instead of every tree.

Summary and Conclusions

In this activity, we’ve:

  1. Classified Type I and Type II error scenarios
  2. Calculated Cohen’s d for pine (paired and unpaired) and horned lizards
  3. Run a priori power analysis to find the n a study needs, including for unequal group sizes with pwr.t2n.test()
  4. Run retrospective power analysis on our own pine needle study
  5. Compared unpaired vs. paired designs and seen what pairing buys in power
  6. Compared SD, SE, and CI as answers to three different questions
  7. Connected pseudoreplication to inflated apparent power

Key takeaways:

  • A priori power planning is the single most useful use of this toolkit
  • Retrospective power is for planning the next study, not excusing a null result
  • Report effect size and power alongside p-values, not instead of them

Reflection Questions

  1. Why is an a priori power analysis only as good as the effect size fed into it?
  2. Why does pwr.t2n.test() beat the old harmonic-mean workaround for unequal groups?
  3. Why can pairing buy more power than adding raw sample size?
  4. How would you explain “our study wasn’t wrong, it just didn’t have enough power” to someone who has never taken a statistics course?
