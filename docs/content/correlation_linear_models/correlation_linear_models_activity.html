Activity: Correlation vs Linear Models

Relationships

In-class activity in two halves: code the correlation on the Nazca booby and Indian rope trick data, then fit the lion regression, build its sums of squares by hand, and test its assumptions.
Author

Bill Perry

Worksheet: Correlation and Linear Regression

📥 Booby data 📥 Rope trick data 📥 Lion data 📥 Tools script (.R) 📥 Script skeleton (.R)

This worksheet runs in two halves, matching the lecture. Parts 1–4 are correlation: two measured variables, one number, no direction. Parts 5–8 are regression: a fitted line, the sums of squares it is made of, and the diagnostics that decide whether to believe it.

Three datasets, all from Whitlock & Schluter:

  • booby_aggression.csv — Example 16.1. Nestling visits and adult aggression in Nazca boobies
  • rope_trick.csv — Example 16.5. Years since seeing the Indian rope trick, and how impressive it is remembered as
  • lion_noses.csv — Example 17.1. Proportion of black on a male lion’s nose, and its age

Part 3 · Correlation assumptions

Pearson’s r assumes both variables are normal, the relationship is linear, and no outlier is driving it.

▶ Run this — the formal test on each variable:

# ── Part 3.1 · Correlation assumptions ──────────────────────────────────
shapiro.test(booby_df$visits_as_nestling)

shapiro.test(booby_df$future_aggression)

▶ Run this — and the picture:

# ── Part 3.2 · Correlation assumptions ──────────────────────────────────
h1 <- ggplot(booby_df, aes(visits_as_nestling)) + geom_histogram(bins = 10)
h2 <- ggplot(booby_df, aes(future_aggression)) + geom_histogram(bins = 10)
q1 <- ggplot(booby_df, aes(sample = visits_as_nestling)) + geom_qq() + geom_qq_line()
q2 <- ggplot(booby_df, aes(sample = future_aggression)) + geom_qq() + geom_qq_line()

(h1 / h2) | (q1 / q2)

✏️ Your turn: Remember H₀ here is “these data ARE normal.” Do both variables pass?

visits: p = __________ pass? ______    aggression: p = __________ pass? ______

✏️ Your turn: One of them lands very close to 0.05 while its QQ plot looks fine. At n = 24, which do you believe, and does it change the coefficient you report?

Part 4 · When normality fails

Same workflow, a dataset that does not cooperate: an impressiveness score, which is bounded and lumpy.

▶ Run this:

# ── Part 4.1 · When normality fails ─────────────────────────────────────
ggplot(rope_df, aes(years_since_seen, impressiveness)) +
  geom_point()

shapiro.test(rope_df$impressiveness)

▶ Run this — both coefficients on the same data:

# ── Part 4.2 · When normality fails ─────────────────────────────────────
cor.test(rope_df$years_since_seen, rope_df$impressiveness)

cor.test(rope_df$years_since_seen, rope_df$impressiveness,
         method = "spearman")

▶ Run this:

# ── Part 5.1 · Fitting a regression ─────────────────────────────────────
ggplot(lion_df, aes(proportion_black, age_years)) +

summary(lion_model)

Part 6 · Sums of squares

The lecture’s centrepiece: build the partition yourself, then let R hand you the same numbers.

▶ Run this:

# ── Part 6.1 · Sums of squares ──────────────────────────────────────────
fitted_age <- predict(lion_model)
mean_age   <- mean(lion_df$age_years)

ss_total <- sum((lion_df$age_years - mean_age)^2)
ss_reg   <- sum((fitted_age - mean_age)^2)
ss_resid <- sum((lion_df$age_years - fitted_age)^2)

c(total = ss_total, regression = ss_reg, residual = ss_resid)

ss_reg + ss_resid

✏️ Your turn: Does the partition add up, and what fraction of the total does the line account for?

ss_reg / ss_total = __________   Where have you seen that number before? ______

Part 7 · Regression assumptions

Every check from here is on the residuals, not the raw data.

▶ Run this — the four standard diagnostic plots:

# ── Part 7.1 · Regression assumptions ───────────────────────────────────
par(mfrow = c(2, 2))
plot(lion_model)
par(mfrow = c(1, 1))

▶ Run this — the formal test on the residuals:

# ── Part 7.2 · Regression assumptions ───────────────────────────────────
shapiro.test(residuals(lion_model))

Part 8 · The figure you hand in

Everything above was for looking. This one is for showing, so it gets the full treatment.

▶ Run this:

# ── Part 8.1 · The figure you hand in ───────────────────────────────────
final_plot <- ggplot(lion_df, aes(proportion_black, age_years)) +
  geom_point(size = 2.5) +
  geom_smooth(method = "lm", colour = "blue") +
  labs(
    title = "Nose pigmentation predicts age in male lions",
    subtitle = "Fitted least-squares line with 95% confidence band",
    x = "Proportion of black on nose",
    y = "Age (years)"
  ) +
  theme_regular(base_size = 12)

final_plot

ggsave(
  "figures/lion_regression.pdf",
  plot   = final_plot,
  width  = 6,
  height = 4,
  units  = "in"
)
