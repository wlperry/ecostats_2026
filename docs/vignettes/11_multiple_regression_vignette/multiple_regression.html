Multiple Regression

Regression with several predictors

Full model, collinearity (VIF), comparing nested models, and Type II tests on Loyn’s forest bird data from lecture.
Author

Bill Perry

📥 Download the R script 📊 Download the data

What multiple regression does

Multiple regression predicts one response from several predictors at once. Each slope is a partial slope: the effect of that predictor while holding the others constant.

\[Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \varepsilon\]

Data: forest bird abundance in 56 forest patches in Victoria, Australia (Loyn 1987), with patch area, distance to the nearest patch and to the nearest larger patch, year isolated, grazing intensity (1–5), and altitude.

Assumptions: the same as simple regression (linearity, normal residuals, equal variance, independence), plus predictors that are not too strongly correlated with each other (collinearity).

Step 1: Load packages and data

Area and distances are strongly right-skewed, so we log-transform them, as in lecture.

  mutate(log_area        = log10(area_ha),

Step 2: Look at the predictors together

A scatterplot matrix shows each predictor against the response and against each other.

Step 3: Fit the full model

full_model <- lm(abundance ~ log_area + log_dist +
                   log_dist_larger + year_isolated +
                   grazing + altitude_m,
                 data = bird_df)

Step 4: Check collinearity

The variance inflation factor (VIF) says how much each slope’s variance is inflated by correlation with the other predictors. VIF > 5 is a warning; > 10 is a problem.

vif(full_model)
       log_area        log_dist log_dist_larger   year_isolated         grazing 
       1.911514        1.654553        2.009749        1.804769        2.524814 
     altitude_m 
       1.467937

All VIFs are below 3, so collinearity is not a concern here.

Step 5: Compare the full model with a reduced model

Drop the predictors that add nothing and test whether the fit got worse. This is a partial F-test of nested models.

reduced_model <- lm(abundance ~ log_area + grazing, data = bird_df)

anova(reduced_model, full_model)

Reading the output:

  • log_area slope: abundance rises by about 6.9 birds for each 10-fold increase in patch area, holding grazing constant.
  • grazing slope: each step up in grazing intensity lowers abundance by about 2.9 birds, holding area constant.
  • Adjusted R² (0.64) penalizes extra predictors; use it to compare models of different size.

Step 8: Write it up

red_aov <- Anova(reduced_model, type = "II")

Forest bird abundance increased with log10 patch area (F1,53 = 28.5, p < 0.001) and decreased with grazing intensity (F1,53 = 16, p < 0.001; multiple regression, R² = 0.65). Distance to other patches, year of isolation, and altitude did not improve the model (partial F-test, p = 0.3).

Report each predictor’s slope or F with df and p, the overall R², and how you chose the final model.
